# Model Portfolio Lab

A paper-traded multi-asset portfolio run with a written process: an [investment policy statement](ips.md), dated decisions committed to git, a monthly factsheet and Brinson-Fachler attribution against a 60/40 global benchmark.

- Goes live: **1 January 2027** (paper only, USD, ETF proxies).
- Factsheets: published on the 2nd of each month once live.

*Paper portfolio for personal research. Not investment advice; no real money.*
